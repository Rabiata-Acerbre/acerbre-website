MT5 setup

One manual terminal permission.

MetaTrader 5 requires users to explicitly allow WebRequest access to the licensing origin. The EA cannot silently add this permission itself.

AppleTree and Bergo setup
  1. Open Tools → Options → Expert Advisors.
  2. Enable WebRequest for the Rabiata licensing URL supplied with the product.
  3. Attach the licensed EA to the intended MT5 chart and enable Algo Trading.

The EA reads the account identifier from the running terminal. There is no license-key field to complete.

Infrastructure boundary

The licensing service authorizes software use. It does not hold broker credentials, place discretionary trades, or guarantee strategy performance.
